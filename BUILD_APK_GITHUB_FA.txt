ساخت APK از طریق GitHub Actions (بدون کامپیوتر)

این بسته هنوز APK آماده نیست؛ سورس پروژه و گردش‌کار ساخت خودکار را دارد.
برای ساخت APK از گوشی اندرویدی:

1) در مرورگر وارد https://github.com شوید و وارد حساب خود شوید.
2) یک مخزن جدید (New repository) بسازید؛ نام پیشنهادی BbitcoinAndroid و حالت Private مناسب است.
3) ZIP را در گوشی از حالت فشرده خارج کنید.
4) همه فایل‌ها و پوشه‌های داخل پروژه، از جمله پوشه مخفی .github، را در مخزن بارگذاری (Upload files) کنید.
   مهم: فایل‌ها را از داخل پوشه پروژه بارگذاری کنید، نه اینکه ZIP را به‌عنوان تنها فایل بگذارید.
5) Commit changes را بزنید.
6) در مخزن، زبانه Actions را باز کنید و گردش‌کار Build Bbitcoin Android APK را انتخاب کنید.
7) اگر خودش شروع نشده، روی Run workflow بزنید و تأیید کنید.
8) پس از پایان موفقیت‌آمیز، در اجرای workflow بخش Artifacts را باز کنید و Bbitcoin-debug-apk را دانلود کنید.
9) ZIP دانلودشده را باز کنید؛ فایل app-debug.apk را اجرا و نصب کنید. ممکن است Android از شما اجازه نصب از این منبع بخواهد.

اگر ساخت شکست خورد، در Actions اجرا را باز کنید و متن خطای قرمز را بررسی کنید.

نکات مهم:
- این APK یک نمونهٔ نمایشی محلی است؛ استخراج آن اثبات کار (proof-of-work) آزمایشی درون برنامه است.
- این پروژه در وضعیت فعلی شبکهٔ همتا‌به‌همتا، گره‌های عمومی، اجماع شبکه، امضای تراکنش، کیف پول واقعی یا انتقال کوین واقعی ندارد.
- عددهای پاداش نمایشی هستند و ارزش پولی ندارند. نام Bbitcoin و نماد BBC به‌تنهایی به معنی اتصال به Bitcoin یا دارایی رسمی نیست.
- APK ساخته‌شده از این workflow نسخهٔ debug است، نه نسخهٔ انتشار امضاشده برای Google Play.
