Bbitcoin Android — نسخهٔ آزمایشی

محتوا:
- رابط برنامهٔ Bbitcoin با لوگوی ₿ و نوشته BBC
- دکمه‌های شروع و توقف استخراج آزمایشی
- شمارندهٔ تلاش‌ها، بلوک‌های آزمایشی و پاداش نمایشی
- پروژهٔ Android WebView برای ساخت APK

مهم:
این نسخه یک نمونهٔ آموزشی محلی است. پاداش‌های نمایشی پول یا رمزارز واقعی نیستند.
این برنامه به شبکهٔ عمومی متصل نیست، تراکنش واقعی انجام نمی‌دهد و با بیت‌کوین سازگار نیست.
کد استخراج جاوااسکریپت صرفاً برای نمایش مفهوم اثبات کار است و استخراج سودآور محسوب نمی‌شود.

ساخت APK:
پیش‌نیازها: JDK 17، Android SDK Platform 35، Android Build Tools، Gradle سازگار.
در پوشهٔ پروژه اجرا کنید:
  gradle assembleDebug
خروجی مورد انتظار:
  app/build/outputs/apk/debug/app-debug.apk

در محیط فعلی Termux، ساخت APK ممکن است تا زمان نصب و تنظیم Android SDK کامل و رفع خطای Gradle انجام نشود.


برای ساخت APK از طریق GitHub Actions، فایل BUILD_APK_GITHUB_FA.txt را بخوانید. گردش‌کار ساخت در .github/workflows/android.yml قرار دارد.
